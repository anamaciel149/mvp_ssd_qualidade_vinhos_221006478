# MVP de Machine Learning — Qualidade de Vinhos

Projeto desenvolvido para a disciplina de Sistemas de Suporte à Decisão da Universidade de Brasília.

## Objetivo

Desenvolver uma análise descritiva e preditiva para classificar vinhos tintos como de alta qualidade ou pertencentes às demais categorias, utilizando suas características físico-químicas.

## Base de dados

Foi utilizada a base Wine Quality, disponibilizada pelo UCI Machine Learning Repository.

## Metodologia

O projeto contempla:

- análise e preparação dos dados;
- análise descritiva;
- criação da variável-alvo;
- Regressão Logística;
- Random Forest;
- validação cruzada;
- avaliação por precisão, recall, F1-score, ROC-AUC e PR-AUC;
- interpretação dos resultados.
